# Mozcライブ変換とZenzの明示変換

入力中はMeltypeのネイティブMozcヘルパーを常駐させ、Mozc本体の辞書・品詞・接続モデルで変換します。MonakIME本体はRustで英日分節・入力状態・ワーカーを実装しています。Meltypeの.NETアプリは起動しません。ヘルパーは公式v1.3.0に同梱されたOSS辞書版を固定ハッシュで配置します。

| 操作               | 処理                                                 |
| ------------------ | ---------------------------------------------------- |
| 入力・末尾削除     | 読みを即時表示し、既定25ms後に最新の入力をMozcへ送る |
| 入力を続ける       | 確定せず、同じ未確定文字列を再変換する               |
| Space・変換キー    | Mozc候補を表示し、別ワーカーでCPUのzenzを要求する    |
| Enter              | 現在の表記を確定する。zenzは要求しない               |
| Esc                | ライブ／明示変換をかなに戻し、次のEscで消去する      |
| 候補選択・文節操作 | 保留中の結果を取り消し、手動選択を保持する           |

例えば `hashidegohanwotaberu` は入力中にMozcが「橋でご飯を食べる」を表示し、Spaceでzenzが「箸でご飯を食べる」を追加します。この例の成功は一般的な変換精度を保証するものではありません。

Backspaceは表示の漢字数ではなく、読みの仮名を1文字ずつ削除します。例えば「日本語」（`nihongo`）からは「にほん」、「きゃく」からは「きゃ」→「き」と削除し、残った読みをMozcが再変換します。未完成の子音と英字も1文字ずつ削除します。Space後の候補選択中は、最初のBackspaceで変換を取り消します。

Shift+←→による文節の伸縮は英字の文節にも使えます。誤って分離された先頭の「M」を選びShift+→で広げると、元の入力を参照して「Mo」「Mona」のように綴りを戻します。対応表は文節編集を始めたときだけ作成し、通常のライブ入力中は保持しません。

`nn` は母音の前で「ん」として確定し、`tanni` は「たんい」、`tanniha` は「たんいは」になります。「こんにちは」「案内します」など従来の綴りと競合する場合は、辞書にある長い単語を優先し、同じ長さなら `nn` の確定を優先します。`shinnyuu` の「しんにゅう」は保持します。境界を明示する `n'` も利用でき、「単に」は `tan'ni` または `tannni` と入力できます。

日本語の単語内に英単語が含まれていても、辞書にある日本語の読みを保護します。例えば `katime`・`katimehatakai` は「かちめ」・「かちめはたかい」となり、途中の `time` を英語として取り出しません。`Google`・`GitHub` など、大文字を含めて入力した英単語や略語は保持します。

Mozcとzenzはそれぞれ単一のワーカーを持ち、保留要求は各最新1件だけです。待機中は条件変数で眠り、定期タイマーでのポーリングを行いません。25msの待ちは新しいキーで更新する1回限りの待機です。Mozcのキャッシュは最大32件、概算512KiBまで、保持する候補文字列は1応答64KiBまでに制限します。実際のキャッシュオブジェクトにはアロケーターの付加情報などもあります。

プロセス間通信はローカルの標準入出力パイプです。ヘルパーは初回のかな入力まで起動せず、モデルは明示変換までロードしません。起動期限は1.5秒、要求期限は300msで、いずれもUIスレッド外です。ヘルパーが停止・異常終了した場合は補助辞書へフォールバックします。失敗したヘルパーを打鍵ごとに再起動しません。復旧にはfcitx5を再起動します。

候補は文節の読みを連結した結果が要求と一致する場合にだけ採用します。ASCII文字が変化する候補を除外するため、`Google`・`GitHub`・`CPU`・`12.5%`・`256MB`の綴りを保持します。未完成のローマ字は末尾に保持します。ユーザー辞書や学習済みの表記は、一致する読み全体・Mozc文節の候補へ反映します。Mozcが作る境界をまたぐ単語のユーザー辞書反映には制約があります。

リセット・フォーカス喪失・機密欄では要求を取り消し、UUIDと世代番号で遅延結果を破棄します。機密欄の判定はアプリケーションがfcitx5へ渡すフラグに依存します。ヘルパーのプロファイルは通常 `~/.local/share/monakime/mozc` で、既存のMozc/Meltypeプロファイルは使いません。旧名NewIMEのプロファイルがあり、新しい場所が存在しない場合は `~/.local/share/newime/mozc` を使います。学習はMonakIMEの `learning.tsv` にまとめて保存します。ヘルパーへの学習書き込み命令は送りません。

## 配置と設定

ヘルパーの実行ファイルはGitリポジトリに含みません。ソースのルートディレクトリーで、x86_64 Linux向けの固定バイナリを取得します。

```sh
./scripts/setup-mozc.sh
# ダウンロード済みの公式アーカイブから配置する場合
./scripts/setup-mozc.sh /path/to/Meltype-1.3.0-linux.zip
```

他のアーキテクチャでは[Mozcヘルパーの説明](../third_party/mozc/README.md)と付属のビルドスクリプトを参照し、対象環境向けにビルドした実行ファイルを `MONAKIME_MOZC_HELPER` で指定します。他のアーキテクチャでの動作は未検証です。ビルドにはネットワークとMozcの開発依存物が必要です。MonakIMEの通常動作は外部通信を行いません。

探索順はインストール先の `libexec/monakime`、ソース内 `third_party/mozc`、既存の `/usr/lib/meltype/mozc` です。設定値は優先して使われます。

```ini
live_conversion=true
live_delay_ms=25
# mozc_helper=/absolute/path/to/meltype_mozc_helper
# mozc_profile=/absolute/path/to/monakime/mozc
```

対応環境変数は `MONAKIME_LIVE_CONVERSION`、`MONAKIME_LIVE_DELAY_MS`、`MONAKIME_MOZC_HELPER`、`MONAKIME_MOZC_PROFILE` です。`MONAKIME_ZENZ=0` ならMozcライブ変換だけ、`MONAKIME_LIVE_CONVERSION=0` なら従来のかな入力＋明示変換になります。

```sh
./build/monakime-cli --live --json 'hashidegohanwotaberu'
./build/monakime-cli --mozc --json 'hashidegohanwotaberu'
./scripts/measure-live.py
```

CLIは従来の辞書・モデル評価との互換性のため、Mozcを使う場合に `--live` または `--mozc` を指定します。fcitx5ではライブ変換が既定で有効です。
