# Third-party sources

Original MonakIME code: Copyright (C) 2026 rirannda, GPL-3.0-or-later. See [COPYRIGHT](COPYRIGHT) for the project notice and scope, and [LICENSE](LICENSE) for the full license text. It independently implements a scored English/Japanese segmentation approach and a dictionary-based kana/kanji lattice; Meltype source files are not vendored into the core.

MonakIME 0.2 implements composition, dictionaries, learning, input state, workers, subprocess communication and CLI in Rust. `native/fcitx_bridge.cpp` adapts the fcitx5 C++ API; `native/llama_bridge.cpp` adapts llama.cpp's model/context/decode API. The pre-migration C++ implementation is preserved in `reference/cpp/` for reading and comparison.

- **Rust dependencies** — Direct dependencies are `libc 0.2.189`, `memmap2 0.9.11`, and `serde_json 1.0.151`. Sources and checksums for the complete resolved graph are pinned in `Cargo.lock`. Registry sources: https://crates.io/crates/libc , https://crates.io/crates/memmap2 , https://crates.io/crates/serde_json . Their MIT/Apache-2.0 notices and the notices for transitive/build dependencies (including Unicode data notices) are preserved under `data/licenses/rust/` and installed with the package. `serde_json` is used by the CLI; the fcitx adapter uses an owned C-ABI view instead of JSON IPC.

The live conversion backend is a separate, persistent **real Mozc engine** process. `third_party/mozc/` contains Meltype v1.3.0's helper source, build definition, Linux build script, credits and provenance, with a MonakIME-specific README; the optional executable is copied unchanged from the official Linux release. This does not run the Meltype .NET application. Helper source and build script: Copyright (C) 2026 Yukishiro, GPL-3.0-or-later. Mozc engine: Google and contributors, BSD-3-Clause plus dictionary/dependency licenses in `MOZC-LICENSE.txt` and `MOZC-CREDITS.html`. Source: https://github.com/yksr-melt/Meltype/tree/v1.3.0/native/mozc ; engine revision `a069a88d4cb5c011de0f9aebb6c149a1c808d904`. The downloaded helper uses the official OSS dictionary, without local UT additions. SHA-256 pins are in `scripts/setup-mozc.sh` and `third_party/mozc/provenance.json`.

- **Meltype** — https://github.com/yksr-melt/Meltype, GPL-3.0-or-later. Algorithm reference: `src/Meltype.Core/Composition/ScoredSegmentation.cs`, main revision `ecb2ba1cb05777e82b3f0b1dcbbba753c0c0b182`. Its English/Japanese DP rewards long dictionary words and penalizes extra boundaries; kana/kanji bunsetsu are supplied by a separate conversion engine. MonakIME is a separate implementation and is not an official Meltype release.
- **llama.cpp / ggml** — https://github.com/ggml-org/llama.cpp, MIT, copyright contributors. Pinned revision `d88040c704c8855c497d46c20675a3d492f70f94`. Full notices are in `third_party/llama.cpp/LICENSE`, `third_party/llama.cpp/licenses/` and the embedded dependency headers. The CPU libraries are statically linked into the addon and CLI. Preserve these notices when distributing binaries.
- **Zenz v3.2 models** — Miwa Keita, Apache-2.0. https://huggingface.co/Miwa-Keita/zenz-v3.2-xsmall-gguf and https://huggingface.co/Miwa-Keita/zenz-v3.2-small-gguf . Model revision, size and SHA-256 are pinned in `scripts/setup-model.sh`. Model weights have their own license; they are downloaded separately and are not stored in this Git repository. The CMake install/package includes the xsmall weights if they have been downloaded to the default source-tree path. The Apache-2.0 license text is in `data/licenses/Apache-2.0.txt`. See `docs/zenzai.md` for the model protocol and limitations.
- **Mozc OSS dictionary** — Google and dictionary authors. https://github.com/google/mozc, source revision `a069a88d4cb5c011de0f9aebb6c149a1c808d904`. Optional `system.nimedic` contains a filtered, deduplicated selection of kana readings, surfaces and word costs from `src/data/dictionary_oss/dictionary00.txt` through `dictionary09.txt`; connection IDs and Mozc's connection model are not included. Preserve **both** `data/licenses/Mozc-LICENSE` and `data/licenses/Mozc-dictionary-LICENSE` (including IPAdic/ICOT/Okinawa notices). `*.sources.json` records input hashes and the output hash. The build tool does not incorporate local uncommitted UT additions.
- **fcitx5** — https://github.com/fcitx/fcitx5, LGPL-2.1-or-later and component-specific notices. MonakIME dynamically links the installed fcitx5 development libraries.

`data/base.tsv`, `data/english.txt` and `data/monakime.svg` are small original bootstrap resources provided with this project. They are not copies of Meltype's word lists. Any additional user/SKK/TSV dictionary retains its original license and is not automatically licensed by MonakIME.
